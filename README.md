# Estefy Lazo's Terrarium

A static website with a 1995 encyclopedia aesthetic, created to celebrate Estefy Lazo's 29th birthday in 2026.

The site presents an open terrarium inspired by a strawberry matcha latte and Asian rainforests. Its style combines strawberry and matcha colors, retro details, botanical illustrations, real plant photos, and a cozy, whimsical mood.

## Contents

The page includes information about:

- Strawberry Begonia Variegated
- Pink Lady / Pink Panther
- Syngonium Neon Robusta
- String of Turtles
- Pink Polka Dot Plant
- Peperomia Napoli Nights
- Pilea glauca
- Pilea depressa
- String of Frogs
- The dragon stone, the terrarium's only decorative piece
- Basic care recommendations for an open terrarium

## How to View It

No installation or dependencies are required.

### Option 1: Open Directly

Open `index.html` in a web browser.

### Option 2: Use a Local Server

From the project folder, run:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000) in your browser.
